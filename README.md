# NitroCall — Nitro Poker Club

Voz e compartilhamento de tela entre amigos, direto de PC a PC, com criptografia ponta a ponta.
Sem conta, sem login, sem servidor de chamada.

**Para entrar:** abra o site no **Chrome** ou no **Edge** do computador, digite o código da sala e o
seu nome. Todo mundo usa o mesmo código (e a mesma senha, se houver).

Este repositório só hospeda o arquivo do site (`index.html`). A chamada não passa pelo GitHub: o
áudio e a tela vão direto entre os PCs (WebRTC, DTLS-SRTP). O código da sala vai depois do `#` no
link de convite e nunca chega ao GitHub.
